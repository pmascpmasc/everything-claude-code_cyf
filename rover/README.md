# 6WD Rocker-Bogie Rover

仿影片中的 6 輪搖臂轉向架（rocker-bogie）越障車：Arduino Uno + L298N + 2×18650 + 6 顆 N20 減速馬達。支援藍牙手機遙控與超音波自動避障兩種模式。

```
rover/
├── cad/rover.scad              # 參數化 3D 列印零件（OpenSCAD）
└── firmware/
    ├── rover/rover.ino         # Arduino 主程式
    ├── rover/rover_logic.h     # 指令解析 / 避障狀態機（純邏輯，可在 PC 測試）
    └── test/test_logic.cpp     # 邏輯單元測試
```

## 機構原理

每側一根**搖臂（rocker）**以 M4 螺栓樞接在車身側板；搖臂前端裝前輪馬達，後端樞接**轉向架（bogie）**，轉向架兩端裝中輪與後輪。左右搖臂由車頂的**差速桿（differential bar）**經兩根球頭連桿相連：一側搖臂抬頭，另一側就被壓低，車身俯仰角維持在兩側平均，六輪都能貼地。

尺寸（側視，以搖臂樞軸為原點，單位 mm）：

| 項目 | 值 |
|------|----|
| 前輪軸 | (75, -55) |
| 轉向架樞軸 | (-47.5, -30) |
| 中 / 後輪軸 | (-10, -55) / (-85, -55) |
| 軸距 | 160（前–中 85、中–後 75） |
| 建議輪徑 | 60（可用 43–65） |
| 車身 | 180 × 110 × 60 |
| 離地間隙 | 約 70（樞軸離地 85） |

所有數值都在 `rover.scad` 頂端，改參數即可。

## 3D 列印

需要 [OpenSCAD](https://openscad.org/)。逐一輸出：

```bash
cd rover/cad
for p in rocker bogie body diff_bar diff_bracket sonar_bracket; do
  openscad -D "part=\"$p\"" -o "$p.stl" rover.scad
done
```

| 零件 | 數量 | 列印方向 |
|------|------|----------|
| rocker | 2 | 平放；切片軟體中鏡像其中一支 |
| bogie | 2 | 平放 |
| body | 1 | 頂板朝下、側板朝上，免支撐 |
| diff_bar | 1 | 平放 |
| diff_bracket | 1 | 底座朝下 |
| sonar_bracket | 1 | 底座朝下 |

建議 PETG 或 PLA+，壁厚 3 圈、填充 30% 以上。不加參數直接開 `rover.scad` 會顯示簡略組合預覽，只供檢查比例。

## 接線

| 來源 | 接到 |
|------|------|
| 電池 + → 開關 | L298N `12V` 與 Uno `VIN` |
| 電池 − | L298N `GND`、Uno `GND`（必須共地） |
| L298N `ENA / IN1 / IN2` | Uno D5 / D7 / D8（左側） |
| L298N `ENB / IN3 / IN4` | Uno D6 / D9 / D10（右側） |
| L298N `OUT1/OUT2` | 左側 3 顆馬達並聯 |
| L298N `OUT3/OUT4` | 右側 3 顆馬達並聯 |
| 藍牙 `TXD` | Uno D2 |
| 藍牙 `RXD` | Uno D3 經 1 kΩ，再以 2 kΩ 接地（5 V → 3.3 V 分壓） |
| 藍牙 `VCC / GND` | Uno 5V / GND |
| HC-SR04 `TRIG / ECHO` | Uno D11 / D12 |
| HC-SR04 `VCC / GND` | Uno 5V / GND |

L298N 的 ENA/ENB 跳帽要**拔掉**，否則無法調速。上電後若某側方向相反，對調該側馬達的兩條線即可（同側三顆的極性要一致）。

## 韌體

上傳 `firmware/rover/` 資料夾（Arduino IDE 開 `rover.ino`，板子選 Arduino Uno）。藍牙接在 SoftwareSerial（D2/D3），上傳不受影響。

藍牙指令（相容常見的 Android「Arduino Bluetooth RC Car」App，鮑率 9600；也可用 USB 序列埠送同樣字元測試）：

| 字元 | 動作 |
|------|------|
| `F` / `B` | 前進 / 後退 |
| `L` / `R` | 原地左 / 右轉（左右反向） |
| `G` / `I` | 左前 / 右前 弧線 |
| `H` / `J` | 左後 / 右後 弧線 |
| `S` | 停止 |
| `0`–`9`、`q` | 速度 0–90%、100% |
| `X` / `x` | 進入 / 離開自動避障 |

安全行為：

- 手動模式下 1 秒沒收到指令就停車（斷線保護）。若你的 App 只在按下時送一次字元，把 `CMD_TIMEOUT_MS` 改成 0。
- 手動前進時前方 25 cm 內有障礙物會自動停住，但仍可後退與轉向。
- 自動模式：前進 → 遇障後退 0.4 s → 右轉 0.45 s → 仍擋住就繼續轉，否則繼續前進。任一手動方向鍵會立即接管。

測試純邏輯（需要 g++）：

```bash
cd rover/firmware/test
g++ -std=c++11 -Wall -I../rover test_logic.cpp -o test_logic && ./test_logic
```

## 組裝順序

1. 馬達塞入搖臂 / 轉向架的方形夾座，輸出軸朝外，M3 止付螺絲輕鎖。轉向架裝在搖臂**外側**；搖臂前輪夾座較高，就是為了讓前輪與轉向架車輪對齊。
2. 轉向架以 M4 螺栓樞接到搖臂後端，螺帽鎖到轉動順暢無晃動。
3. 搖臂以 M4 螺栓樞接到車身側板，中間夾墊片。
4. 差速支架鎖在車頂，差速桿以 M4 樞接；兩端用球頭連桿接到搖臂上方的 M3 耳孔。車放平時調整連桿長度，讓差速桿水平。
5. 裝上電路板、電池盒、超音波支架（鎖在車頂前緣），馬達線從車頂兩個大孔穿上來。
6. 先架空車輪測試方向，再落地測試。

## 注意事項與未驗證項目

- **影片標示為 AI 生成內容**，影片中的機構不一定能照做；本設計是依 rocker-bogie 標準原理重新設計的版本，不是逐件複製。
- 韌體已在 PC 跑過邏輯測試並用 avr-gcc 編譯成功（Uno：4.7 KB Flash），**但沒有在實體硬體上跑過**。
- CAD 已能正常輸出 STL，**但沒有實際列印與組裝驗證**；L298N、電池盒的鎖孔位置是常見規格估計值，請先量實物再改 `l298_*`、`batt_holes`。
- 差速連桿長度、搖臂與車身間墊片厚度需依實物微調。
- L298N 每通道約 2 A。N20 堵轉電流約 0.3–0.6 A，三顆並聯可用；若改用較大的 TT / 370 馬達，三顆同時堵轉可能超過，需改用兩片驅動板或更大電流的驅動器。L298N 本身會壓降約 2 V，馬達實際約 5–6 V。
- HC-05/06 是傳統藍牙，**iPhone 無法連線**。你的影片是 iPhone 錄的，所以 BOM 預設用 HM-10；iOS 端需找能對 HM-10 送自訂字元的 BLE 遙控 / 序列 App（我沒有實測特定 App）。上表的「Arduino Bluetooth RC Car」App 只有 Android 版。
